# Getting help

- **Questions, ideas, and "how do I…"**: ask in
  [GitHub Discussions](https://github.com/defilantech/socair/discussions).
  Check the [README](README.md) and the documentation in [docs/](docs) first;
  most environment inputs and commands are described there.
- **Bugs and feature requests**: open an
  [issue](https://github.com/defilantech/socair/issues/new/choose) with its
  template. A legitimate model that got a FAIL or a LEAD it should not have
  has its own template: false positives are bugs we measure against.
- **Vulnerabilities and detection bypasses**: report them privately, as
  [SECURITY.md](SECURITY.md) describes. Never in a public issue, discussion,
  or pull request. A malicious file that earns a PASS is a detection bypass.

Socair has few maintainers, so an answer can take a few days. There is no paid
support.
